Dataset Overview

This page provides details about the cherry leaf dataset used to train and test the MildewCNN model.

Dataset Details

  • Source: The dataset was sourced from the PlantVillage Dataset on Kaggle, containing images of cherry leaves.
  • Total Images: 1000 images (500 Healthy, 500 Powdery Mildew).
  • Image Size: All images are uniform at 256x256 pixels, saved as JPEG or PNG.
  • Split Ratio: Train (70%, 700 images), Validation (20%, 200 images), Test (10%, 100 images).
  • Classes: Healthy, Powdery Mildew.

The dataset is organized into `inputs/cherry-leaves_dataset/` with subfolders for `train`, `validation`, and `test`, each containing `healthy` and `powdery_mildew` subfolders. This structure ensures balanced training and evaluation of the model.
